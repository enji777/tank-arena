# Пепельная арена

Небольшая браузерная 2D action-RPG в духе Soulslike. Игра работает на компьютере и телефоне; игроки с разных устройств могут встретиться в одной онлайн-комнате.

## Что уже есть

- Ближний бой с лёгкой и сильной атакой, затратой выносливости и уклонением с короткими кадрами неуязвимости.
- Костёр, лечебные фляги, души за победы, потеря душ при смерти и возможность вернуть их на месте гибели.
- Улучшение уровня у костра: здоровье, выносливость и урон оружия.
- Три типа обычных врагов и босс с предупреждаемыми атаками и второй фазой.
- Кооперативная комната на двух игроков и переподключение после обрыва связи.
- Управление клавиатурой и мышью, а также экранные кнопки и касательное прицеливание.
- Локальное сохранение уровня, душ и победы над боссом в браузере.

## Запуск локально

Нужен Node.js 18 или новее.

```sh
npm install
npm start
```

Откройте `http://localhost:3000`. Чтобы пригласить второго игрока, нажмите «Ссылка другу» и отправьте ссылку. Для игры с другого устройства оба устройства должны иметь доступ к одному развёрнутому серверу.

## Управление

| Действие | ПК | Телефон |
| --- | --- | --- |
| Движение | WASD или стрелки | Экранный крестовик |
| Прицеливание | Мышь | Коснуться врага или арены |
| Лёгкая атака | Левая кнопка мыши | УДАР |
| Сильная атака | Shift | СИЛЬНЫЙ |
| Уклонение | Пробел | УКЛОН |
| Лечебная фляга | Q | ФЛЯГА |
| Отдых у костра | E | КОСТЁР |
| Улучшение у костра | R | УЛУЧШ. |

## Структура

- `server.js` — комнаты, симуляция боя, враги и сетевое состояние.
- `public/index.html` — интерфейс, адаптивная раскладка и кнопки телефона.
- `public/game.js` — управление, отрисовка Canvas и локальное сохранение.
